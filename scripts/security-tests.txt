# The security lane: the tests that feed phantab a hostile input and need a refusal.
# scripts/security-check.sh runs them and fails when one is missing, skipped, ignored or not ok.
# docs/TESTING.md § Security lane says what each group stands for.
#
# One test per line:   <when> <target> <test name>
#   when     all      runs on every machine
#            unix     macOS only today (the test is not built on Windows, or is ignored there)
#            chrome   needs real Chrome: run with --chrome
#   target   lib      phantab's unit tests; the name is the full path (engine::tests::...)
#            ext:<f>  extension/test/<f>.test.mjs; the name is the test's title
#            <file>   crates/phantab/tests/<file>.rs
#
# Add a test here when it proves a hostile input is refused: a web origin, a forged peer, a changed
# file, a page that lies. A renamed test must be renamed here too, or the lane fails.
